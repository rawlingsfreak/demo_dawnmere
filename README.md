# Dawnmere — playable demo

A village life sim where the woods have something under them. One third Stardew, one third Skyrim,
one third Diablo.

This repository holds the **downloads only**. The game's source lives elsewhere.

## Download

Go to **[Releases](../../releases)** and take the one for your machine:

| | |
|---|---|
| **Mac** | [`Dawnmere-mac.zip`](https://github.com/rawlingsfreak/demo_dawnmere/releases/download/v0.1-demo/Dawnmere-mac.zip) |
| **Windows** | [`Dawnmere-win.zip`](https://github.com/rawlingsfreak/demo_dawnmere/releases/download/v0.1-demo/Dawnmere-win.zip) |

Each download already contains `READ_ME_FIRST.md`. Please read it — it covers the keys and what is
worth writing down.

## Opening it

**Mac** — unzip, then **right-click `Dawnmere` → Open**. Double-clicking will refuse. If macOS still
blocks it: System Settings → Privacy & Security → scroll down → **Open Anyway**. The game is
unsigned, which is why it does that. It is not a warning about the game.

**Windows** — unzip, and keep **`Dawnmere.exe` and `Dawnmere.pck` in the same folder**. Separate them
and it will not start. Windows will say "Windows protected your PC" → **More info** → **Run anyway**.

It saves by itself — three slots, when you sleep, when you go through a door, and when you quit.
**Esc** opens the menu for sound and full screen.

## It ends on purpose

When you reach the end you will see a card that says **"Dawnmere — The demo ends here."** That is the
ending, not a crash.

## Already known — no need to report these

- The town is laid out badly in places, and its ground is one flat grey.
- Townsfolk have their own faces but no walking animation, so they stand still.
- Wren is drawn in different proportions from everyone else.
- The keys cannot be rebound yet.

Everything else is fair game. **Where you got stuck is the most useful thing you can send back** —
the moment, not the fix.
